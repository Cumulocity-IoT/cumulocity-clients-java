DEPRECATION NOTICE

The Cumulocity SDK - Java MQTT Service Client library is deprecated and will be removed once the Cumulocity IoT MQTT Service reaches General Availability (GA). It should not be used for new development.

Migration Required

All microservices and external application clients currently using this Java client SDK should migrate to a direct connection with the Cumulocity IoT Messaging Service using the Apache Pulsar protocol. Please refer to the official documentation for more details and examples.

Transition Period

The MQTT Service Java client SDK will remain available and supported until the MQTT Service GA date. During this transition, clients can use this Java client SDK in parallel with direct connections to the Messaging Service.
